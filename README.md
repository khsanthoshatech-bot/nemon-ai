# 🚀 Nemon AI

Nemon AI is a modern AI-powered chat application built with React, TypeScript, Vite, and OpenRouter. It provides a sleek workspace-based interface for interacting with multiple AI models through a fast and responsive chat experience.

## ✨ Features

- 🤖 AI Chat powered by OpenRouter
- 🔐 Clerk Authentication
- 💬 Multi-session Chat Workspaces
- 🌙 Premium Dark UI
- ⚡ Real-time AI Response Streaming
- 📱 Responsive Design
- 🎨 Animated Particle Background
- 📝 Chat History Persistence
- 🔒 Secure API Integration
- 🚀 Fast Vite Build System

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/khsanthoshatech-bot/nemon-ai.git
```

Navigate to project:

```bash
cd nemon-ai
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
OPENROUTER_API_KEY=your_api_key
VITE_CLERK_PUBLISHABLE_KEY=your_clerk_key
```

Start development server:

```bash
npm run dev
```

## 🚀 Deployment

Build project:

```bash
npm run build
```

Deploy to:

- Vercel
- Netlify
- Cloudflare Pages

## 🔒 Environment Variables

```env
OPENROUTER_API_KEY=
VITE_CLERK_PUBLISHABLE_KEY=
```

Never commit real API keys to GitHub.
